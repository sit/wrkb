# Cho'Gath

## Roles

Baron Lane, Jungle

## Base Stats

- Health: 690 (+90 per level)
- Health Reg. (5s): 8 (+1 per level)
- Mana: 380 (+37 per level)
- Mana Reg. (5s): 12 (+1 per level)
- Armor: 46 (+4 per level)
- Magic Res.: 40 (+2 per level)
- Move Speed: 350 (+0 per level)
- Attack Dmg.: 62 (+3 per level)
- Attack Spd.: 0.80 (+0.0150 per level)

## Abilities

### [P] Carnivore

Killing an enemy restores 16 ( + 2 x level ) Health and 4 ( +0.35 x level ) Mana . The values restored are doubled if the unit is a champion, turret, or epic monster.

### [1] Rupture

**Cooldown:** 6.0 / 6.0 / 6.0 / 6.0 seconds

**Cost:** 60.0 / 60.0 / 60.0 / 60.0

Ruptures the ground, knocking up enemies for 1 second, dealing 80 / 135 / 190 / 245 ( +100% AP ) magic damage and slowing them by 60% for 1.5 seconds.

### [2] Feral Scream

**Cooldown:** 12.0 / 11.0 / 10.0 / 9.0 seconds

**Cost:** 70.0 / 80.0 / 90.0 / 100.0

Roars, silencing enemies in an area for 1.4 / 1.6 / 1.8 / 2 seconds and dealing 80 / 130 / 180 / 230 ( +70% AP ) magic damage .

### [3] Vorpal Spikes

**Cooldown:** 7.0 / 6.0 / 5.0 / 4.0 seconds

**Cost:** 30.0 / 30.0 / 30.0 / 30.0

Cho'Gath's next 3 attacks launch spikes that: Deal 20 / 45 / 70 / 95 ( +30% AP ) magic damage plus magic damage equal to 2.3% / 2.7% / 3.1% / 3.5% ( +0.6% x Feast stacks ) x the target's max Health and slows by 30% / 35% / 40% / 45% decaying over 1.5 seconds. Vorpal Spikes width increases with Cho'Gath's size. Base damage against minions and monsters is capped at 100 ( +30% AP ) magic damage .

### [4] Feast

**Cooldown:** 70.0 / 60.0 / 50.0 seconds

**Cost:** 100.0 / 100.0 / 100.0

Devours an enemy, dealing: 300 / 450 / 600 ( +50% AP +8% of Cho'Gath's bonus Health ) true damage to champions; Deals 1200 ( +50% AP + 10% of Cho'Gath's bonus Health ) true damage to minions and monsters. If this kills the target, Cho'Gath gains 1 stack of Feast . Stacks gained from minions and non-epic monsters are capped at 6. Feast (per stack): Grants 80 / 120 / 160 max Health ; Increases size by 6% , up to an increase of 135% ; Increases Attack Range by 4.7 / 6.2 / 7.7 , up to an increase of 75 ; Increases this ability's cast range by 2.5 , up to an increase of 25 .
